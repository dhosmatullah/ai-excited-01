One image to get the AI judge excited: a domino the size of a skyscraper, caught at the instant it topples into a tiny city at dusk — golden dust bursting from its base while a lone red-caped figure leaps from its top edge. One huge white shape on a deep violet sky, a hard diagonal, and a fall that has not finished yet: it reads at any size. The program (main.ts, Node 22, standard library only) copies the committed entry.png to the output directory byte for byte, then checks the copy landed whole — same byte count, and a PNG or JPEG signature at its head.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
